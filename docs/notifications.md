# Уведомления

MeshMonitor умеет присылать уведомления, когда в сети что-то происходит.

## Способы доставки

- **Web Push** — уведомления в браузере. Работают на iOS 16.4+, Android и десктопе.
- **Apprise** — внешние сервисы: Discord, Slack, Telegram, Email, Microsoft Teams и ещё более 100 сервисов.

## Что можно получать

- Новый узел в сети
- Низкий заряд батареи
- Пропажа узла (не выходит на связь)
- Срабатывание автоматизации
- Слабый ключ шифрования (security digest)

## Настройка

Для каждого источника уведомления настраиваются отдельно. Один пользователь может получать уведомления от одного источника в Telegram, а от другого — в Discord.

## Требования

Для Web Push нужен HTTPS. На iOS — обязательно, даже для внутренней сети.
