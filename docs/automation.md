# Автоматизация

MeshMonitor умеет выполнять действия автоматически — без вашего участия.

## Готовые автоматизации

- **Auto Responder** — отвечает на входящие сообщения по шаблону.
- **Auto Acknowledge** — подтверждает получение сообщений.
- **Auto Traceroute** — периодически проверяет маршруты до нод.
- **Auto Announce** — периодически отправляет статус.
- **Auto Remote LocalStats** — опрашивает удалённые ноды и строит графики их здоровья.
- **Scheduled Messages** — отправляет сообщения по расписанию.

## Automation Engine

Это конструктор «когда это — делай то». Вы собираете автоматизацию сами из блоков:

- **WHEN** — триггер (сообщение, телеметрия, расписание, геозона).
- **RULE** — условие (сравнение чисел, проверка текста, фильтр по источнику).
- **THEN** — действие (отправить сообщение, уведомление, запустить скрипт).

## Скрипты

Можно запускать свои скрипты на Python, Node.js или Shell. Скрипт получает данные через переменные окружения и возвращает результат, который можно использовать дальше.

## Geofence

Триггер срабатывает, когда нода входит в заданную область, выходит из неё или остаётся внутри. Область рисуется прямо на карте.
