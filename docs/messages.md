# Сообщения

MeshMonitor работает как полноценный клиент для общения в сети.

## Что можно делать

- **Читать и отправлять сообщения** в общие каналы.
- **Личные сообщения** (DM) напрямую другим нодам.
- **История переписки** — все сообщения сохраняются в базе.
- **Поиск** — по каналам и личным сообщениям (Ctrl+K).
- **Реакции** — отправлять tapback на сообщения.
- **Вложения** — обмениваться файлами через дед-дроп.

## Unified Messages

Если у вас несколько источников (Meshtastic, MeshCore, MQTT), их сообщения отображаются в одном окне. Каждое помечено значком протокола, из которого пришло.
