# Карта и анализ сети

Главная визуальная ценность MeshMonitor. На карте в реальном времени отображаются все ноды сети.

## Что видно на карте

- **Ноды** — маркеры всех узлов, которые слышит ваша станция.
- **Цвет маркера** — зависит от качества сигнала (SNR). Зелёный — отличный, красный — плохой.
- **Трассы traceroute** — линии маршрутов между нодами, окрашенные по SNR.
- **Тепловая карта покрытия** — где сеть слышит ноды с GPS.
- **Следы движения** — история перемещений нод.
- **Авиация** — ноды, которые летят выше рельефа, помечаются значком самолёта.

## Что можно сделать

- **Кликнуть на ноду** — открыть детали: имя, модель, батарея, версия прошивки, количество хопов, источник позиции.
- **Поиск** — скрыть все маркеры, кроме совпадающих с запросом.
- **Spiderfy** — развести маркеры, которые наложились друг на друга в одной точке.
- **Измерить расстояние** — выбрать две ноды и получить расстояние между ними.
- **Follow mode** — следить за одной нодой, карта автоматически центрируется при движении.
- **3D-режим** — просмотр рельефа местности.

## Настройки отображения

- **Фильтр по транспорту** — показать только ноды, пришедшие через RF, UDP или MQTT.
- **Полярная сетка** — кольца дальности и азимуты для антенн.
- **Слои GeoJSON** — накладывать свои карты поверх базовой.
