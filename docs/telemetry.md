# Телеметрия и графики

MeshMonitor собирает данные с датчиков нод и представляет их в виде графиков, шкал и числовых виджетов.

## Виджеты

Каждый виджет можно переключать между тремя режимами:

| Режим | Что показывает |
| :--- | :--- |
| **Chart** | График изменений во времени |
| **Gauge** | Круговая шкала с текущим значением |
| **Numeric** | Крупная цифра |

Переключение — кнопками в заголовке виджета. Настройки сохраняются в браузере.

## Что можно отслеживать

- Уровень батареи
- Температура
- Влажность
- Напряжение
- Давление
- Шумовая полка
- Загрузка канала
- Время работы

## Настройка диапазона шкалы

Для режима Gauge можно задать минимум и максимум. Это полезно, если значение выходит за стандартные пределы.

## Дашборд

Виджеты можно закрепить на главном дашборде — тогда все ключевые показатели видны сразу, без перехода на страницу ноды.
