# Мульти-источники

Один экземпляр MeshMonitor может одновременно собирать данные из нескольких сетей — Meshtastic, MeshCore и MQTT.

## Как это работает

Каждый источник — это отдельное подключение. У него свои настройки, свой планировщик, свои права доступа и свой список нод.

## Типы источников

| Тип | Что подключает |
| :--- | :--- |
| `meshtastic_tcp` | Нода Meshtastic по TCP |
| `meshcore` | Устройство MeshCore (USB или TCP) |
| `mqtt_broker` | Встроенный MQTT-брокер |
| `mqtt_bridge` | Клиент к внешнему MQTT-брокеру |

## Unified режим

Если источников несколько, их данные можно смотреть вместе — в режиме Unified. Сообщения, телеметрия и traceroutes объединяются в одном окне, а каждое помечается значком протокола.

## Права доступа

Для каждого источника права настраиваются отдельно. Пользователь может быть админом на одном, только читать другой и вообще не видеть третий.
